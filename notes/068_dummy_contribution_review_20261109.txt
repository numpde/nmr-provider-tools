Resulting boundary
------------------
science.py contains provider-owned types and scientific functions only. binding.py
contains the contribution adapter. Equal JSON shapes use separate types and format
identities when their meanings differ. Shared codecs own structural admission;
science owns scientific rejection. Live prepared state is represented by a typed
CalculationState, not an untyped mapping.

No compatibility aliases were added for the previous dummy names. The example is
not a public compatibility baseline and no real provider has adopted those names.

Focused evidence
----------------
The final local files were compiled with Python 3.13. The direct science checks ran
seven tests covering the weighted lifecycle, correction after rejection,
call-specific input types, numeric normalization, non-finite values, state
retention after an unloaded-model refusal and empty-input rejection. All seven
passed.

A small local contract harness ran two adapter checks covering typed weighted
execution/progress and translation of an empty sum into ScientificRejection. Both
passed.

The revised installed-native typed-boundary and embedded-host test modules were
compiled. They were not executed against the complete installed provider-core
package in this environment. Canonical contained qualification, the wider native
lane, real-provider adoption, release, dependency updates and deployment remain
unverified by this review.

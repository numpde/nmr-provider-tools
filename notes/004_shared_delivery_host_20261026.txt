Deliberate adaptations:
  Build/install the issued GitHub wheel and closed install lock, never a copied
  package source or another provider image. Retain offline capture, immutable
  image ID/label admission and bounded operation-owned cleanup.
  Neutral binding TOML is the sole operator authority. Bounded rendering reads
  that definition without opening credentials. It admits derived socket lengths
  before granting private files. Startup verifies the selected definition hash.
  Grant only exact credential/CA paths below /grants; deduplicate shared trust
  inputs. Only an external API proxy receives its resolver file. These original
  files must remain available for restarts. No science package is imported.
  The daemon has network none, reaches API proxies through private socket volumes
  mounted read-only, and owns queue and producer IPC writes. Each producer gets
  only its binding's IPC volume read-only plus the configured supplementary GID.
  Queue, producer IPC and API-proxy socket state are Docker named volumes.
  Root initialization receives only those volumes plus CHOWN. It preserves
  correctly owned nonempty roots and refuses unexpected ownership or modes.
  Queue name, IPC digest, daemon UID/GID and socket leaf preserve existing grants.
  Proxy startup waits for initialization; daemon readiness checks every local
  intake with bounded status requests, without listing the queue or calling API.

Lifecycle:
  up selects the complete DELIVERY_BINDINGS and immutable SHARED_RUNTIME_IMAGE.
  status/logs/down select PROJECT from actual typed container ownership, without
  requiring a host recipe or the original inputs. A never-started, mount-free
  operation container atomically reserves the project for cooperating mutations;
  existing CID admission and operation cleanup own it. An unresolved reservation
  requires inspection; it is not automatically treated as stale.
  Existing project containers must be retired by their owner before up. Down
  settles the daemon before its API proxies, removes exact owned container IDs
  and retains every volume. Held/discard require the project stopped, an existing
  project-owned queue, the definition and exact API/provider selectors. Their
  finite helper receives no credential or trust grants.
  Existing queues are adopted in place; no importer or automatic rollback is
  claimed. Consumer repositories own producer quiescence and coordinated cutover.

This port keeps GitHub credentials on the host, clean committed source capture,
exact installed-artifact qualification, canonical destination/rewrite admission,
existing-release refusal, native retirement facts, draft upload, downloaded-byte
comparison and final publication. Nested Make operations use controller_native
so cancellation awaits their owned cleanup. No checkout work directory is used.

Preparation and publication are explicit operations because the actual public
artifacts, logs and authored prose must be available for inspection before the
external write. publish/prepare writes five artifacts plus build/test logs and a
copy of the one committed versioned release note. publish/release captures those
same files privately, requires all five exact qualification hashes and unchanged
source/note, then follows the draft/download/compare/public flow. It does not
rebuild or rerun package tests during publication. There is no proof registry or
prose scanner. Release notes use one source line per paragraph/list item.

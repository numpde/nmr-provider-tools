## Findings and revisions

1. A confirmed StartDeadlineExpired response was being treated as ambiguous
   delivery. The parent now propagates that actual SDK pre-admission refusal,
   removes its provisional owner, and keeps the channel usable. Other uncertain
   acknowledgements still retain their original operation without replay.

2. Cached completion could hide an already known channel failure, and a lost
   acknowledgement could hide subsequent native retirement forever. Parent
   observations now reconcile remote scientific facts with local communication,
   stop and native-retirement facts. Child exit expires child-only result bytes;
   native resource release does not invent a scientific result or disposer success.

3. Interim review caught equal child revisions containing newly known scientific
   facts. The parent accepts those facts while canonical decoded failure evidence
   prevents equivalent reconstructed exceptions from manufacturing revisions.
   Known native receipt also prevents needless positive-wait I/O after retirement.

4. Remote diagnostics lacked useful child locations. The wire now retains bounded
   file/function/line facts and causal records, with no source or locals. One
   immutable decoded record serves both observation comparison and the protected
   diagnostic consumer. Foreign mutable attributes do not supply those facts.

5. Round 2 identified a source-derived secret-fragment counterexample: truncating
   an oversized message before known-secret redaction can remove the rest of a
   secret. Oversized type/message/note text is now omitted whole with an explicit
   fixed marker. Bounded independent causes and structured frames remain. The
   loss of a useful oversized prefix is an intentional tradeoff; there is no
   second redaction protocol or transfer of parent secrets into the worker.

6. Missing actual-child proof designs now use independent witnesses and explicit
   barriers: construction/initialization once across analyses, cancelled startup
   after partial acquisition, independent initialization/close failures, active
   worker death, an effect before acknowledgement loss, confirmed start expiry,
   retained-result expiry, and host-driven retirement of still-held science.
   Re-observation checks original ownership and allowances without restarting work.

7. The test launchers now grant their scientific environment explicitly and check
   excluded environment/descriptor identity. This is deployment policy exercised
   by tests, not a claim that RunnerSession sanitizes a supervisor's environment.
   The existing native runner remains the only termination/reaping owner.

8. The installed NMRPeak test now checks foreign-allocation state and projects a
   real child parse failure through protected diagnostics. The latter proves
   proposed load-location/filename-redaction assertions, not an actual-child
   opaque-message-secret scenario. That scenario has its own wire-to-consumer
   unit regression. The API-dependent diagnostic assertion stays outside the
   standard-library-only native lane.

9. The current SDK/examples guide now describes session custody, installed
   factories, supported data, common bindings, payload/frame limits, synchronous
   control limits, scientific/native retirement and outstanding qualification.

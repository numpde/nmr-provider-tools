Native operation-deadline fixture startup timing
----------------------------------------------

Owner: provider-core native test qualification.
Priority: minor; investigate if it repeats or that fixture changes.

During the retained-controller work, one intermediate installed unit run failed
test_absolute_operation_deadline_stops_connected_but_idle_owner while receiving
the fixture worker PID: ConnectionResetError. The later complete 486-case run
passed, with no native runner implementation or timeout change. A product defect
has not been established; avoid rewriting the runner or extending its deadline
merely to suppress a one-off test result.

Evidence: /tmp/sdk-owned-driver-green.log (480 cases, one error) and
/tmp/sdk-owned-driver-races-green.log (486 cases, all passed). These temporary
logs identify the observed runs; the shared decision note preserves their
interpretation if the files are later removed.

Bounded diagnostic rendering across actual consumer sinks
--------------------------------------------------------

Owner: provider-core rendering, with each provider owning its logging envelope.
Priority: follow-up after the qualified outage/deadline release and deployment;
revisit sooner if a real incident loses protected diagnostic evidence.

Constructed witnesses produced a 43,290-byte record, an atomic 4,096-byte pipe
refusal, and invalid JSON after a consumer's 8,192-character slice. The inspected
live incident records were 694-3,141 bytes and valid; those observations do not
prove the general case safe. Retain valid JSON, bounded UTF-8 bytes including
the actual envelope, coherent references, explicit omissions, and primary and
independent cleanup evidence. Never substitute raw exception text or tracebacks.

The existing proposal at /tmp/provider-core-bounded-diagnostics-proposal is an
experiment, not an accepted implementation. Its fixed eight-node priority quota
has no established justification. Review cause/group versus incidental-context
ordering and repeated-reference accounting without making traversal unbounded.
Include safe symbolic DNS reasons without copying raw private exception text.

Qualification must use actual sinks: NMRNet's atomic pipe allowance, Magnet's
logging envelope and escaping, and SECS's blocking handler and fatal writer have
different contracts. A shared renderer must expose its budget clearly; consumers
must supply the allowance remaining after their own framing. Do not add another
provider-local serializer. D125, D131 and D136 in the running decision note retain
the design obligations. This work does not block the independently qualified
availability, deadline and cancellation corrections in 0.5.1.

Absolute caller deadlines through the chat carrier
-------------------------------------------------

Owner: provider-core ChatEndpoint, with the model caller supplying its deadline.
Trigger: a caller needs an explicit no-dispatch-after-turn-expiry contract, or
the next change to the chat deadline interface.

ChatEndpoint.complete currently constructs JSON and an HTTP request before the
transport starts its relative exchange allowance. It exposes no absolute cap;
an outer asyncio.timeout cannot preempt synchronous construction. A constructed
installed-package witness shows the original transport task can enter after that
outer allowance expires. Only _perform was stubbed to record entry: this does
not prove real network dispatch, a live incident or a violated explicit absolute
carrier contract. Existing transport I/O bounds remain a separate guarantee.

If that stricter caller contract is adopted, pass one explicit absolute deadline
through the existing chat/transport owner, checking after construction and before
dispatch and retaining it for original cleanup observation. Do not infer timeout
contexts dynamically, copy the carrier into a provider or add another Task owner.
Qualify actual dispatch refusal under controlled slow construction/pacing before
claiming the effect boundary. D151 records the alternatives and deferral rationale;
the existing qualified deployment and published artifacts remain unchanged.

## Observed unit qualification failure and correction

The first full unit run on 65dff2e3 counted 1116 tests (1024 executed, 92 privacy
skips), with one failure in 173.269s. The unchanged API cancellation witness
expected aggregate-deadline evidence while both aggregate and inner httpcore read
limits were 20ms. If the inner read timeout won, it truthfully started gated
cleanup before the aggregate timer could cancel pending network I/O; the test
then incorrectly required aggregate-cancellation evidence. Its close-started
barrier did not distinguish which timer authored that cleanup.

read deadline to select aggregate cancellation. The same narrow test-only patch
now applies to the failing witness. All original caller-interruption identity,
owned relationships, transport retirement, aggregate evidence and retry assertions
remain. No production transport or deadline changed. Three independent reviewers
accepted the actual correction. The unchanged isolated selection passed ten tests,
consistent with intermittence; the corrected selection also passed all ten.
A passing isolated rerun did not erase the failed full receipt.

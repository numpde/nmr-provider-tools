# provider-core 0.5.15

Providers can share interpreter mechanics while retaining scientific dispatch
and endpoint outcome policy. Tool conversations support plain tool feedback
without an added user instruction and an optional raw argument-byte limit.

The single-attempt chat carrier decodes compressed responses with separate
success/error limits and forwards an optional absolute exchange and retirement
deadline. Existing byte-limit defaults remain unchanged. Original HTTP-head,
failure and uncertain-retirement evidence remain available to the owner.

Release provenance now uses the same authored module inventory as the
wheelhouse bundle, including its network-recovery module.

D001 -- Implementation ownership (20:22 UTC)
-------------------------------------------

Serious alternatives:
A. The shared coordinator authors every repository change. This gives one editor
   but serializes four substantial consumer migrations and discards the existing
   repo owners' task context.
B. Each existing repository coordinator authors its own bounded slices; the shared
   coordinator owns SDK integration, the common contract, and this log. Require
   independent review across the boundaries before accepting each slice.

Choice: B. The four owners have already inspected and jointly reviewed their
consumer contracts. Repository ownership makes useful parallel work possible
without concurrent writers to one checkout. It does not allow independent changes
to the common design: bring consequential choices here before acting on them.

Next evidence: each owner reports its current tree, one first slice, genuine
implementation gaps, serious alternatives, and focused validation. No blanket
approval to rewrite a whole runtime without intermediate review.
